# Bimax Pitch Deck Figma Plugin Generator

This folder contains the complete, ready-to-run Figma Plugin that programmatically generates all **11 Presentation Slides (1920x1080)** on your Figma canvas with native AutoLayout, dark theme styling, typography, cards, badges, and the phone mockup.

---

## 🚀 How to Run in Figma (Takes 30 Seconds)

### Step 1: Open Figma
1. Open the **Figma Desktop App** (or Figma in your browser).
2. Create or open any Figma design file where you want the slides to be placed.

### Step 2: Import the Plugin
1. In the top-left menu, click the **Figma logo** (or press `Cmd + /` / `Ctrl + /`).
2. Navigate to **Plugins** → **Development** → **Import plugin from manifest...**.
3. Select the file:  
   `/Users/vishsiddharth/Desktop/BimaxApk/figma_plugin/manifest.json`

### Step 3: Run the Plugin
1. Click **Plugins** → **Development** → **Bimax Pitch Deck Generator**.
2. **Done!** Figma will instantly create all 11 slides side-by-side (1920×1080 each) and automatically zoom into them.
