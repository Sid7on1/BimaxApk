### 1. Verification Summary & Technical Verdict

The research document has been audited and verified against Cloudflare One official documentation, Apple macOS `launchd` service standards, and real-world cellular Carrier-Grade NAT (CGNAT) behaviors:

1. **Automatic WebSocket Upgrade**: Validated. Cloudflare Tunnel requires **no special WebSocket flags** in `config.yml`. It acts as a transparent reverse proxy that auto-negotiates the `HTTP/1.1 101 Switching Protocols` handshake, provided the zone-level **WebSockets toggle** is enabled in the Cloudflare Dashboard (**Network** $\rightarrow$ **WebSockets**).
2. **`OriginRequestConfig` Accuracy**: Validated. Keys (`noTLSVerify`, `connectTimeout`, `tlsTimeout`, `tcpKeepAlive`, `keepAliveConnections`, `keepAliveTimeout`) strictly map to `github.com/cloudflare/cloudflared/pkg/config`.
3. **Transport Protocol Selection (`protocol: http2`)**: Highly recommended for development. Cloudflare Tunnel defaults to QUIC (HTTP/3 over UDP). Certain mobile hotspots and aggressive corporate firewalls throttle or block UDP packets; setting `protocol: http2` (over TCP) prevents silent tunnel drops.
4. **macOS `launchd` Specification**: Validated. The plist syntax strictly adheres to Apple GUI session standards (`gui/$(id -u)`), with `SuccessfulExit = false` and `ThrottleInterval = 10` preventing CPU runaway crashes.
5. **Cellular NAT & Cloudflare 100s Idle Limits**: Validated. Cloudflare Free/Pro tiers enforce a strict 100-second idle WebSocket timeout. Mobile carrier CGNAT states frequently expire after 30–60 seconds. A **25-second WebSocket ping/pong heartbeat interval** is the optimal sweet spot.
6. **Network Reconnection & Wi-Fi Switching**: Validated. `cloudflared` recovers automatically once outbound connectivity is restored because its identity is cryptographic (credentials JSON) rather than IP-bound. Application-layer retry logic is required on both client and host to recover gracefully from brief socket drops.

### 2. Production `cloudflared` Configuration (`config.yml`)

Save to `~/.cloudflared/config.yml` (or `/etc/cloudflared/config.yml`):

```yaml
tunnel: bimax-mac-tunnel
credentials-file: /Users/vishsiddharth/.cloudflared/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.json

# Force HTTP/2 over TCP instead of QUIC to survive aggressive UDP NAT timeouts on cellular/hotspot networks
protocol: http2

ingress:
  # Primary WebSocket / HTTP API origin on local macOS daemon (self-signed HTTPS)
  - hostname: bimax-bridge.yourdomain.com
    service: https://localhost:8443
    originRequest:
      # Bypass TLS verification for local self-signed dev certificates
      noTLSVerify: true

      # Connection timeouts & connection pooling
      connectTimeout: 10s        # Timeout to establish TCP connection to localhost:8443
      tlsTimeout: 10s            # Timeout for TLS handshake with localhost:8443
      tcpKeepAlive: 30s          # TCP keepalive probes sent to local daemon
      keepAliveConnections: 100  # Max idle keepalive connections in pool
      keepAliveTimeout: 90s      # Idle keepalive timeout to local origin

  # Catch-all rule (Mandatory for cloudflared validation)
  - service: http_status:404
```

### 4. Code Implementation: Host & Client Heartbeat Engine

To guarantee zero silent disconnects, implement the heartbeat on both ends using these exact code patterns:

#### A. macOS Host Daemon: Go (`github.com/gorilla/websocket`)
This Go implementation enforces the **25-second Ping interval** and sets a **60-second Read Deadline**. If the mobile client dies or loses network silently, the host detects it and frees system resources.

```go
package bridge

import (
	"log"
	"net/http"
	"time"

	"github.com/gorilla/websocket"
)

const (
	// Time allowed to write a message to the peer.
	writeWait = 10 * time.Second

	// Time allowed to read the next pong message from the peer.
	// Must be greater than pingPeriod so a pong can arrive in time.
	pongWait = 60 * time.Second

	// Send pings to peer with this period. Must be less than pongWait,
	// less than mobile CGNAT drop windows (~30s), and less than Cloudflare's 100s timeout.
	pingPeriod = 25 * time.Second
)

var upgrader = websocket.Upgrader{
	ReadBufferSize:  4096,
	WriteBufferSize: 4096,
	CheckOrigin: func(r *http.Request) bool {
		// Enforce origin validation in production
		return true
	},
}

func HandleWebSocket(w http.ResponseWriter, r *http.Request) {
	ws, err := upgrader.Upgrade(w, r, nil)
	if err != nil {
		log.Printf("WebSocket upgrade failed: %v", err)
		return
	}
	defer ws.Close()

	// Configure read deadline and pong handler
	ws.SetReadLimit(512 * 1024) // 512KB max message size
	ws.SetReadDeadline(time.Now().Add(pongWait))
	ws.SetPongHandler(func(string) error {
		// When mobile client responds with PONG, extend read deadline
		ws.SetReadDeadline(time.Now().Add(pongWait))
		return nil
	})

	// Channel to signal reader termination to writer
	done := make(chan struct{})

	// Goroutine: Read pump (listens for incoming commands from Android)
	go func() {
		defer close(done)
		for {
			msgType, payload, err := ws.ReadMessage()
			if err != nil {
				if websocket.IsUnexpectedCloseError(err, websocket.CloseGoingAway, websocket.CloseAbnormalClosure) {
					log.Printf("WebSocket read error: %v", err)
				}
				break
			}
			log.Printf("Received message (%d bytes, type %d)", len(payload), msgType)
			// Route payload to E2EE decryptor & agent executor
		}
	}()

	// Ticker: Send Ping frames every 25 seconds
	ticker := time.NewTicker(pingPeriod)
	defer ticker.Stop()

	for {
		select {
		case <-ticker.C:
			ws.SetWriteDeadline(time.Now().Add(writeWait))
			// Protocol-level RFC 6455 Ping frame
			if err := ws.WriteMessage(websocket.PingMessage, nil); err != nil {
				log.Printf("Failed to send ping: %v", err)
				return
			}

		case <-done:
			return
		}
	}
}
```

#### B. Android Client: Kotlin (`okhttp3.WebSocket`)
OkHttp provides native, hardware-efficient WebSocket connection pooling and ping/pong handling.

```kotlin
package com.bimax.mobile.data.network

import okhttp3.*
import okio.ByteString
import java.util.concurrent.TimeUnit
import android.util.Log

class BimaxWebSocketClient(
    private val serverUrl: String,
    private val cfClientId: String,
    private val cfClientSecret: String
) {
    private var webSocket: WebSocket? = null

    // Build OkHttpClient with built-in 25-second ping interval
    private val client = OkHttpClient.Builder()
        // Automatically sends RFC 6455 Ping frames every 25 seconds;
        // drops connection and triggers onClosed if Pong is not received.
        .pingInterval(25, TimeUnit.SECONDS)
        .connectTimeout(10, TimeUnit.SECONDS)
        .readTimeout(0, TimeUnit.MILLISECONDS) // Indefinite read for persistent streams
        .retryOnConnectionFailure(true)
        .build()

    fun connect(listener: BimaxSocketListener) {
        val request = Request.Builder()
            .url(serverUrl) // wss://bimax-bridge.yourdomain.com
            // Cloudflare Access Service Token Headers
            .addHeader("CF-Access-Client-Id", cfClientId)
            .addHeader("CF-Access-Client-Secret", cfClientSecret)
            .build()

        webSocket = client.newWebSocket(request, object : WebSocketListener() {
            override fun onOpen(webSocket: WebSocket, response: Response) {
                Log.d("BimaxWS", "Connected to Mac Bridge via Cloudflare")
                listener.onConnected()
            }

            override fun onMessage(webSocket: WebSocket, text: String) {
                listener.onTextMessage(text)
            }

            override fun onMessage(webSocket: WebSocket, bytes: ByteString) {
                listener.onEncryptedFrame(bytes.toByteArray())
            }

            override fun onFailure(webSocket: WebSocket, t: Throwable, response: Response?) {
                Log.e("BimaxWS", "Connection failed: ${t.message}, response: $response")
                listener.onDisconnected(t)
                scheduleReconnect()
            }

            override fun onClosing(webSocket: WebSocket, code: Int, reason: String) {
                webSocket.close(1000, null)
                listener.onDisconnected(null)
            }
        })
    }

    private fun scheduleReconnect() {
        // Trigger exponential backoff reconnect logic
    }

    fun send(data: ByteArray) {
        webSocket?.send(ByteString.of(*data))
    }

    fun disconnect() {
        webSocket?.close(1000, "User initiated disconnect")
    }

    interface BimaxSocketListener {
        fun onConnected()
        fun onTextMessage(text: String)
        fun onEncryptedFrame(bytes: ByteArray)
        fun onDisconnected(throwable: Throwable?)
    }
}
```
