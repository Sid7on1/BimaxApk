### 1. Verification Summary & Privacy Guard Model

Autonomous AI agents frequently request debugging logs, terminal dumps, and config files from developers. If a user inadvertently pastes an environment file (`.env`), a cloud credential, or a database connection string into the chat prompt, transmitting that unredacted string over public cellular networks creates catastrophic exposure risks.

The **On-Device Secret Firewall** executes entirely on the mobile device inside the Android client **before** any network serialization or E2EE encryption occurs:
1. **Precompiled ReDoS-Safe Regex Suite**: Evaluates prompts against prefix-anchored, linear-matching regular expressions designed to avoid nested backtracking.
2. **Context-Preserving Placeholder Generation**: Replaces detected secrets with formatted tokens like `[REDACTED_API_KEY_xxxx]`, exposing the last 4 characters (`xxxx`) so the developer retains situational context.
3. **Shannon Entropy Fallback**: Inspects high-entropy alphanumeric strings ($H(S) \ge 4.5$) to catch custom or unindexed proprietary secrets.
4. **Pre-Transmission Blocking Confirmation**: Intercepts the UI thread with a blocking confirmation modal (`AlertDialog` / Jetpack Compose Dialog) displaying exact redacted keys and types before network transmission.

```
+-----------------------------------------------------------------------------------------+
|                               ON-DEVICE DLP FIREWALL PIPELINE                           |
```

### 2. Comprehensive High-Speed ReDoS-Safe Regex Specifications

| Secret Type | Verified Regex Pattern | Format Description & Character Bounds |
| :--- | :--- | :--- |
| **AWS Access Key ID** | `\b(?:AKIA\|ASIA)[0-9A-Z]{16}\b` | 20 chars; `AKIA` (long-term) or `ASIA` (STS session) followed by 16 alphanumeric characters. |
| **AWS Secret Access Key** | `(?<![A-Za-z0-9])[0-9A-Za-z/+]{40}(?![A-Za-z0-9])` | 40-character Base64 token bounded by non-alphanumeric lookarounds. |
| **GitHub Classic PAT** | `\bghp_[A-Za-z0-9]{36}\b` | 40 chars total (`ghp_` prefix + 36 alphanumeric characters). |
| **GitHub Fine-Grained PAT** | `\bgithub_pat_[A-Za-z0-9_]{82}\b` | Modern granular token (`github_pat_` prefix + 82 characters). |
| **OpenAI API Key** | `\bsk-[A-Za-z0-9_-]{32,}\b` | `sk-` prefix with 32+ Base64URL characters (covers project and legacy keys). |
| **Anthropic API Key** | `\bsk-ant-[A-Za-z0-9_-]{80,}\b` | `sk-ant-` prefix followed by 80+ Base64URL characters (`sk-ant-api03-`, `sk-ant-oat01-`). |
| **SSH Private Key Header** | `-----BEGIN (?:RSA\|DSA\|EC\|OPENSSH) PRIVATE KEY-----` | Multiline header uniquely flagging PEM/OpenSSH private key blocks. |
| **PostgreSQL / DB URL** | `\bpostgres(?:ql)?://[^:\s]+:[^@\s]+@[^/\s]+(?::\d+)?/[^\s?]+` | Complete URI containing embedded plaintext `user:password@host` credentials. |
| **Stripe Secret Key** | `\bsk_(?:live\|test)_[0-9a-zA-Z]{24,32}\b` | Stripe API keys (`sk_live_` or `sk_test_`). |
| **Slack User/Bot Token** | `\bxox[baprs]-[0-9a-zA-Z]{10,48}\b` | Slack bot (`xoxb-`), user (`xoxp-`), or app (`xoxa-`) authentication tokens. |

### 3. Shannon Entropy Analysis for Unstructured Secrets

For arbitrary proprietary API keys that lack standard vendor prefixes, the scanner calculates the Shannon Entropy $H(S)$ of standalone tokens ($\ge 20$ characters):

$$H(S) = -\sum_{i=1}^{n} P(c_i) \log_2 P(c_i)$$

Where $P(c_i) = \frac{\text{count}(c_i)}{|S|}$.
- Pure English prose / code identifiers typically exhibit $H(S) \in [2.5, 3.8]$.
- High-entropy cryptographic keys and pseudo-random hashes exhibit **$H(S) \ge 4.5$** (for Base64/alphanumeric) and **$H(S) \ge 3.2$** (for Hex).

### 4. Complete Production Kotlin Engine (`SecretScanner.kt`)

```kotlin
package com.bimax.mobile.security

import kotlin.math.log2

data class DetectedSecret(
    val type: String,
    val value: String,
    val placeholder: String
)

data class RedactionResult(
    val sanitizedText: String,
    val secrets: List<DetectedSecret>
)

object SecretScanner {

    // 1. Precompiled Prefix & Structure Regexes (ReDoS Safe)
    private val awsAccessKeyIdRegex = Regex(
        pattern = """\b(?:AKIA|ASIA)[0-9A-Z]{16}\b""",
        option = RegexOption.IGNORE_CASE
    )

    private val awsSecretKeyRegex = Regex(
        pattern = """(?<![A-Za-z0-9])[0-9A-Za-z/+]{40}(?![A-Za-z0-9])""",
        option = RegexOption.IGNORE_CASE
    )

    private val githubClassicPatRegex = Regex("""\bghp_[A-Za-z0-9]{36}\b""")
    private val githubFineGrainedPatRegex = Regex("""\bgithub_pat_[A-Za-z0-9_]{82}\b""")

    private val openAIKeyRegex = Regex("""\bsk-[A-Za-z0-9_-]{32,}\b""")
    private val anthropicKeyRegex = Regex("""\bsk-ant-[A-Za-z0-9_-]{80,}\b""")

    private val sshPrivateKeyRegex = Regex(
        pattern = """-----BEGIN (?:RSA|DSA|EC|OPENSSH) PRIVATE KEY-----""",
        option = RegexOption.MULTILINE
    )

    private val postgresUrlWithPasswordRegex = Regex(
        pattern = """\bpostgres(?:ql)?://[^:\s]+:[^@\s]+@[^/\s]+(?::\d+)?/[^\s?]+"""
    )

    private val stripeSecretKeyRegex = Regex("""\bsk_(?:live|test)_[0-9a-zA-Z]{24,32}\b""")
    private val slackTokenRegex = Regex("""\bxox[baprs]-[0-9a-zA-Z]{10,48}\b""")

    // List of deterministic type + regex pairs
    private val patterns: List<Pair<String, Regex>> = listOf(
        "AWS_ACCESS_KEY_ID"         to awsAccessKeyIdRegex,
        "AWS_SECRET_ACCESS_KEY"     to awsSecretKeyRegex,
        "GITHUB_PAT_CLASSIC"        to githubClassicPatRegex,
        "GITHUB_PAT_FINE_GRAINED"   to githubFineGrainedPatRegex,
        "OPENAI_API_KEY"            to openAIKeyRegex,
        "ANTHROPIC_API_KEY"         to anthropicKeyRegex,
        "SSH_PRIVATE_KEY"           to sshPrivateKeyRegex,
        "POSTGRES_DATABASE_URL"     to postgresUrlWithPasswordRegex,
        "STRIPE_SECRET_KEY"         to stripeSecretKeyRegex,
        "SLACK_AUTH_TOKEN"          to slackTokenRegex
    )

    /**
     * Scans input text, replaces sensitive credentials with context-preserving placeholders,
     * and returns the list of detected secrets.
     */
    fun redact(text: String): RedactionResult {
        var sanitized = text
        val secrets = mutableListOf<DetectedSecret>()

        // Pass 1: Deterministic Pattern Scanning
        patterns.forEach { (type, regex) ->
            regex.findAll(sanitized).forEach { match ->
                val token = match.value

                // Deduplicate identical occurrences
                if (secrets.none { it.value == token }) {
                    val suffix = token.takeLast(4)
                    val placeholder = "[REDACTED_${type}_${suffix}]"

                    secrets += DetectedSecret(
                        type = type,
                        value = token,
                        placeholder = placeholder
                    )

                    sanitized = sanitized.replace(token, placeholder)
                }
            }
        }

        // Pass 2: Shannon Entropy Scan for Unstructured High-Entropy Secrets (>= 24 chars)
        val candidateTokens = sanitized.split(Regex("[\\s\"',;=()]+"))
        for (candidate in candidateTokens) {
            if (candidate.length in 24..128 && !candidate.startsWith("[REDACTED_")) {
                val entropy = calculateShannonEntropy(candidate)
                if (entropy >= 4.5 && secrets.none { it.value == candidate }) {
                    val suffix = candidate.takeLast(4)
                    val placeholder = "[REDACTED_HIGH_ENTROPY_KEY_${suffix}]"

                    secrets += DetectedSecret(
                        type = "HIGH_ENTROPY_SECRET (H=${String.format("%.2f", entropy)})",
                        value = candidate,
                        placeholder = placeholder
                    )

                    sanitized = sanitized.replace(candidate, placeholder)
                }
            }
        }

        return RedactionResult(
            sanitizedText = sanitized,
            secrets = secrets
        )
    }

    /**
     * Computes Shannon Entropy: H(S) = -sum(P(c) * log2(P(c)))
     */
    fun calculateShannonEntropy(input: String): Double {
        if (input.isEmpty()) return 0.0
        val frequencyMap = mutableMapOf<Char, Int>()
        for (char in input) {
            frequencyMap[char] = (frequencyMap[char] ?: 0) + 1
        }

        var entropy = 0.0
        val len = input.length.toDouble()
        for (count in frequencyMap.values) {
            val p = count / len
            entropy -= p * (log2(p))
        }
        return entropy
    }
}
```

### 5. UI Confirmation Interceptors: Android Views & Jetpack Compose

#### Android Traditional Views Implementation (`AlertDialog`):
```kotlin
package com.bimax.mobile.security

import android.app.AlertDialog
import android.content.Context

fun sendPromptWithRedaction(
    context: Context,
    originalPrompt: String,
    actuallySend: (String) -> Unit
) {
    val redaction = SecretScanner.redact(originalPrompt)

    if (redaction.secrets.isEmpty()) {
        // No secrets detected; proceed immediately
        actuallySend(originalPrompt)
        return
    }

    val message = buildString {
        appendLine("Potential sensitive credentials detected in your prompt:")
        appendLine()
        redaction.secrets.forEachIndexed { index, secret ->
            appendLine("${index + 1}. ${secret.type} → ${secret.placeholder}")
        }
        appendLine()
        appendLine("Sensitive values will be masked with placeholders before transmission over the network.")
    }

    AlertDialog.Builder(context)
        .setTitle("Security Warning: Secrets Detected")
        .setMessage(message)
        .setCancelable(false)
        .setPositiveButton("Send Redacted") { _, _ ->
            actuallySend(redaction.sanitizedText)
        }
        .setNegativeButton("Cancel / Edit", null)
        .show()
}
```

```kotlin
package com.bimax.mobile.ui.components

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Warning
import androidx.compose.material3.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.text.font.FontFamily
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import com.bimax.mobile.security.DetectedSecret

@Composable
fun SecretRedactionDialog(
    detectedSecrets: List<DetectedSecret>,
    onConfirmSendRedacted: () -> Unit,
    onDismiss: () -> Unit
) {
    AlertDialog(
        onDismissRequest = onDismiss,
        icon = {
            Icon(
                imageVector = Icons.Default.Warning,
                contentDescription = "Security Alert",
                tint = MaterialTheme.colorScheme.error
            )
        },
        title = {
            Text(
                text = "Sensitive Credentials Detected",
                fontWeight = FontWeight.Bold,
                fontSize = 18.sp
            )
        },
        text = {
            Column(modifier = Modifier.fillMaxWidth()) {
                Text(
                    text = "Bimax identified the following credentials in your prompt. They will be masked before leaving this device:",
                    fontSize = 13.sp,
                    color = MaterialTheme.colorScheme.onSurfaceVariant
                )
                Spacer(modifier = Modifier.height(12.dp))
                LazyColumn(
                    modifier = Modifier
                        .fillMaxWidth()
                        .heightIn(max = 180.dp)
                        .background(MaterialTheme.colorScheme.surfaceVariant, RoundedCornerShape(8.dp))
                        .padding(8.dp),
                    verticalArrangement = Arrangement.spacedBy(6.dp)
                ) {
                    items(detectedSecrets) { secret ->
                        Row(
                            verticalAlignment = Alignment.CenterVertically,
                            modifier = Modifier.fillMaxWidth()
                        ) {
                            Text(
                                text = secret.type,
                                fontSize = 11.sp,
                                fontWeight = FontWeight.SemiBold,
                                color = MaterialTheme.colorScheme.primary,
                                modifier = Modifier.weight(1f)
                            )
                            Text(
                                text = secret.placeholder,
                                fontSize = 11.sp,
                                fontFamily = FontFamily.Monospace,
                                color = MaterialTheme.colorScheme.onSurface
                            )
                        }
                    }
                }
            }
        },
        confirmButton = {
            Button(
                onClick = onConfirmSendRedacted,
                colors = ButtonDefaults.buttonColors(containerColor = MaterialTheme.colorScheme.error)
            ) {
                Text("Send Redacted")
            }
        },
        dismissButton = {
            TextButton(onClick = onDismiss) {
                Text("Cancel & Edit")
            }
        }
    )
}
```
