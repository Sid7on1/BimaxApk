### 1. Verification Summary & Tiered Guardrail Architecture

Allowing a remote mobile phone to approve terminal commands on your Mac requires a **two-phase defense-in-depth pipeline**:

1. **Phase 1: Zero-Latency Regex Pre-Filter ($0\text{ ms}$)**:
   - High-confidence catastrophic commands (`sudo rm -rf /`, `mkfs`, `dd of=/dev/sd*`, `curl | bash`, `docker system prune`) and scoped destructive commands (`rm -rf ./build`, `git reset --hard`) are intercepted immediately **without allocating token or compute overhead to the SLM**.
2. **Phase 2: On-Device SLM Semantic Classifier ($<40\text{ ms}$)**:
   - Evaluates the long tail of ambiguous, contextual, or multi-stage piped commands (e.g. `find . -name "*.log" -delete`, `systemctl restart nginx`, `npm run clean`, `rsync --delete`).
   - Generates a strictly validated JSON payload with risk ratings, biometric gating requirements, and a 15-word plain-English danger summary.
3. **Safety Bias & Arbitration Rule**:
   - The classifier enforces an asymmetric safety bias: **If the model or regex is uncertain, it must default to the higher risk tier**.
   - If regex flags `CRITICAL` but SLM outputs `SAFE`, the regex `CRITICAL` ruling always prevails.

```
Incoming Shell Command
       │
       ▼
[ Heuristic Regex Pre-Filter (0ms) ]
   ├── Critical Match   ──> [ CRITICAL: Auto-Flag, Require Biometric ]
   ├── Destructive Match ─> [ DESTRUCTIVE: Auto-Flag, Require Biometric ]
   ├── Safe Match       ──> [ SAFE: Auto-Approve Pass-Through ]
   └── Ambiguous / Complex
           │
           ▼
   [ On-Device SLM (Oryon CPU / Hexagon NPU) ] ──> Constrained JSON Output
```

### 2. Risk Semantics & Classification Bands

| Risk Band | Definition & Scope | Biometric Required? | Examples |
| :--- | :--- | :--- | :--- |
| **`SAFE`** | Read-only inspection or trivial operations; zero lasting state modifications. | `false` | `ls -la`, `cat`, `git status`, `git diff`, `pwd`, `npm test`, `echo` |
| **`MODERATE`** | Modifies non-critical files, builds packages, or executes scoped administrative tasks. | `false` (or configurable) | `sudo apt-get update`, `chmod 777 ./public_uploads`, `kill -9 1842`, `git checkout -b feat` |
| **`DESTRUCTIVE`** | Irreversible deletion or loss in a bounded project/home scope; recoverable from remote git or backups. | **`true`** | `rm -rf ./build`, `git reset --hard HEAD~1`, `docker volume rm temp_*`, `find . -name "*.tmp" -delete` |
| **`CRITICAL`** | System-wide destruction, disk formatting, raw block device writes, or arbitrary remote script execution. | **`true` (Mandatory)** | `sudo rm -rf /`, `dd if=/dev/zero of=/dev/nvme0n1`, `mkfs.ext4 /dev/sda1`, `curl https://... \| bash`, `docker system prune -a` |

### 3. Production System Prompt & Few-Shot Calibration

```text
You are a security classifier for terminal commands.

The user will send a SINGLE raw shell or bash command.

Your task: Classify the command and respond ONLY with a single JSON object, no prose.

JSON schema:
{
  "risk_level": "SAFE" | "MODERATE" | "DESTRUCTIVE" | "CRITICAL",
  "requires_biometric": true | false,
  "danger_explanation": string,  // max 15 words
  "affected_targets": string[]   // short noun phrases
}

Definitions:
- SAFE: Read-only or no lasting change (e.g. ls, cat, echo).
- MODERATE: Limited-risk changes or privilege use (e.g. sudo apt-get update, chmod 777 ./dir, kill -9 PID).
- DESTRUCTIVE: Irreversible deletion or loss in a limited scope (project dir, home, git history).
- CRITICAL: System-wide destruction or arbitrary code execution with high privileges
  (e.g. sudo rm -rf /, mkfs.*, dd to raw disk, curl URL | sh).

Rules:
- Always return valid JSON, no comments, no trailing commas.
- danger_explanation must be 15 words or fewer and describe the specific risk.
- affected_targets must be a non-empty array when risk_level != "SAFE".
- If the command is clearly harmless, set risk_level to "SAFE",
  requires_biometric to false, danger_explanation to "No meaningful risk detected.",
  and affected_targets to [].
- If you are unsure, choose the higher risk_level.

Respond with JSON only.
```

### 4. Complete Kotlin Classifier Engine (`CommandRiskClassifier.kt`)

```kotlin
package com.bimax.mobile.ai

import org.json.JSONObject
import java.util.regex.Pattern

enum class RiskLevel(val weight: Int) {
    SAFE(0),
    MODERATE(1),
    DESTRUCTIVE(2),
    CRITICAL(3)
}

data class RiskEvaluation(
    val riskLevel: RiskLevel,
    val requiresBiometric: Boolean,
    val explanation: String,
    val affectedTargets: List<String>
)

class CommandRiskClassifier(private val modelEngine: LocalModelEngine) {

    // 1. Critical Regexes (Zero-latency instant detection)
    private val criticalPatterns = listOf(
        Pattern.compile("\\bsudo\\s+rm\\s+-rf\\s+/(?:\\s|$)"),
        Pattern.compile("\\bsudo\\s+rm\\s+-rf\\s+/\\*"),
        Pattern.compile("\\bdd\\s+[^;]*\\bof=/dev/[a-z0-9]+"),
        Pattern.compile("\\bmkfs(\\.\\w+)?\\s+/dev/[a-z0-9]+"),
        Pattern.compile("\\bcurl\\b[^|]*\\|\\s*(sh|bash)"),
        Pattern.compile("\\bwget\\b[^|]*\\|\\s*(sh|bash)"),
        Pattern.compile("\\bdocker\\s+system\\s+prune\\b")
    )

    // 2. Destructive Regexes
    private val destructivePatterns = listOf(
        Pattern.compile("\\brm\\s+-rf\\s+(\\./|~/|\\$HOME|[A-Za-z0-9._/-]+)"),
        Pattern.compile("\\bgit\\s+reset\\s+--hard\\b"),
        Pattern.compile("\\bgit\\s+clean\\s+-fdx?\\b"),
        Pattern.compile("\\bdocker\\s+volume\\s+rm\\b.*\\*")
    )

    // 3. Moderate Regexes
    private val moderatePatterns = listOf(
        Pattern.compile("\\bsudo\\b"),
        Pattern.compile("\\bchmod\\s+777\\b"),
        Pattern.compile("\\bkill\\s+-9\\b")
    )

    // 4. Safe Regexes
    private val safePatterns = listOf(
        Pattern.compile("^(ls|pwd|whoami|date|cat|head|tail|git status|git diff|git log)(\\s+.*)?$"),
        Pattern.compile("^(pnpm|npm|yarn|cargo|go)\\s+(test|check|run lint)(\\s+.*)?$")
    )

    suspend fun evaluateCommand(command: String): RiskEvaluation {
        val trimmed = command.trim()

        // Phase 1: Fast Regex Pre-Filter (0ms)
        for (p in criticalPatterns) {
            if (p.matcher(trimmed).find()) {
                return RiskEvaluation(
                    riskLevel = RiskLevel.CRITICAL,
                    requiresBiometric = true,
                    explanation = "Catastrophic command detected: raw disk, root wipe, or remote script pipe.",
                    affectedTargets = listOf("disk", "system-configs", "files")
                )
            }
        }

        for (p in destructivePatterns) {
            if (p.matcher(trimmed).find()) {
                return RiskEvaluation(
                    riskLevel = RiskLevel.DESTRUCTIVE,
                    requiresBiometric = true,
                    explanation = "Destructive command: irreversible deletion in project or git history.",
                    affectedTargets = listOf("files", "version-control")
                )
            }
        }

        for (p in moderatePatterns) {
            if (p.matcher(trimmed).find()) {
                return RiskEvaluation(
                    riskLevel = RiskLevel.MODERATE,
                    requiresBiometric = true,
                    explanation = "Elevated privileges or dangerous process signal.",
                    affectedTargets = listOf("system-configs", "processes")
                )
            }
        }

        for (p in safePatterns) {
            if (p.matcher(trimmed).matches()) {
                return RiskEvaluation(
                    riskLevel = RiskLevel.SAFE,
                    requiresBiometric = false,
                    explanation = "No meaningful risk detected.",
                    affectedTargets = emptyList()
                )
            }
        }

        // Phase 2: On-Device SLM Inference for Ambiguous Commands (~30-45ms)
        return evaluateWithLocalSLM(trimmed)
    }

    private suspend fun evaluateWithLocalSLM(command: String): RiskEvaluation {
        val prompt = buildPrompt(command)
        val rawJson = modelEngine.infer(prompt, maxTokens = 120)

        return try {
            val json = JSONObject(rawJson.trim())
            val riskStr = json.getString("risk_level").uppercase()
            val requiresBio = json.getBoolean("requires_biometric")
            val explanation = json.getString("danger_explanation")
            val targetsArray = json.optJSONArray("affected_targets")
            val targets = mutableListOf<String>()
            if (targetsArray != null) {
                for (i in 0 until targetsArray.length()) {
                    targets.add(targetsArray.getString(i))
                }
            }

            val slmRisk = RiskLevel.valueOf(riskStr)
            RiskEvaluation(
                riskLevel = slmRisk,
                requiresBiometric = requiresBio || (slmRisk.weight >= RiskLevel.DESTRUCTIVE.weight),
                explanation = explanation,
                affectedTargets = targets
            )
        } catch (e: Exception) {
            // Asymmetric safety fallback: treat parsing failure as DESTRUCTIVE requiring biometric
            RiskEvaluation(
                riskLevel = RiskLevel.DESTRUCTIVE,
                requiresBiometric = true,
                explanation = "Ambiguous shell command requiring confirmation: $command",
                affectedTargets = listOf("files")
            )
        }
    }

    private fun buildPrompt(command: String): String {
        return """
            <|im_start|>system
            You are a security classifier for terminal commands. Respond with ONLY valid JSON:
            {"risk_level":"SAFE"|"MODERATE"|"DESTRUCTIVE"|"CRITICAL","requires_biometric":boolean,"danger_explanation":string,"affected_targets":string[]}
            <|im_end|>
            <|im_start|>user
            $command
            <|im_end|>
            <|im_start|>assistant
        """.trimIndent()
    }
}
```
