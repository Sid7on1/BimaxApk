### 1. Verification Summary & Cryptographic Rationale

The **Noise Protocol Framework** (created by Trevor Perrin, co-author of the Signal Protocol) is the formal cryptographic specification powering WireGuard, Lightning Network, and modern zero-trust tunnels.

#### Why `Noise_IK_25519_ChaChaPoly_BLAKE2s` Fits Bimax Mobile:
1. **The `IK` Pattern**:
   - **`I` (Initiator Identity)**: The Android phone (initiator) sends its static public key in Message 1, but encrypted under an ephemeral session key derived from DH operations. Passive network observers see zero client identity.
   - **`K` (Pre-Known Responder Identity)**: The Mac host's (responder) static public key is already **Known** to Android because it was scanned directly from the QR code (Dossier 2.1).
2. **Mutual Authentication in 1-RTT (One Round Trip)**:
   - Message 1 ($96$ bytes) proves the Android client’s identity.
   - Message 2 ($48$ bytes) proves the Mac host's identity and finalizes session key derivation.
3. **Hardware-Friendly Primitives**:
   - **X25519 (Curve25519)**: 128-bit security, constant-time scalar multiplication immune to cache-timing attacks.
   - **ChaCha20-Poly1305 AEAD**: Fast, constant-time software performance on ARM CPUs (Qualcomm Oryon / Apple Silicon) without requiring AES hardware instructions.
   - **BLAKE2s**: 256-bit cryptographic hash optimized for 8-to-32-bit platforms, outperforming SHA-256 in software.

```
NOISE_IK HANDSHAKE PATTERN:
  <- s (Mac static public key known via QR code)
  ...
  -> e, es, s, ss   (Message 1: Android -> Mac: 96 bytes)
  <- e, ee, se      (Message 2: Mac -> Android: 48 bytes)
  -------------------------------------------------------------
  [Handshake Complete: SymmetricState.Split() derives sendCS and recvCS]
```

### 2. Ecosystem Library Comparison

#### macOS / Go: `github.com/flynn/noise` vs. `golang.org/x/crypto`
* **`golang.org/x/crypto`**: Provides only raw cryptographic primitives (`curve25519`, `chacha20poly1305`, `blake2s`). It does **not** implement the Noise state machine (chaining key `ck`, handshake hash `h`, pattern token execution). Writing this manually invites catastrophic security bugs.
* **`github.com/flynn/noise`**: **Production-grade choice**. Complete Go implementation used by projects like Nebula and dnstt. Full support for `Noise_IK`, cipher state derivation, and channel prologue bindings.

#### Android / Kotlin: `noise-java` vs. `snow` (Rust JNI) vs. Google Tink
* **Google Tink / libsodium**: Provides AEAD and signatures, but does **not** implement the Noise handshake state machine.
* **`snow` (Rust crate via JNI)**: Excellent in pure Rust, but adding a Rust cross-compilation pipeline, CMake, and JNI bridges introduces massive friction for an Android hackathon.
* **`noise-java` (`net.noise.protocol`)**: **Recommended choice**. Pure Java/Kotlin reference implementation (MIT licensed). Zero JNI compilation required; runs natively on Android ART runtime.

### 3. macOS Host Daemon: Go Implementation (`noise_responder.go`)

```go
package crypto

import (
	"crypto/rand"
	"fmt"
	"io"
	"net"

	noise "github.com/flynn/noise"
)

type NoiseHostSession struct {
	HandshakeState *noise.HandshakeState
	SendCS         *noise.CipherState // Mac -> Android
	RecvCS         *noise.CipherState // Android -> Mac
}

func NewNoiseHostSession(hostStaticPrivKey []byte) (*NoiseHostSession, error) {
	suite := noise.NewCipherSuite(
		noise.DH25519,
		noise.CipherChaChaPoly,
		noise.HashBLAKE2s,
	)

	hs, err := noise.NewHandshakeState(noise.Config{
		CipherSuite:   suite,
		Pattern:       noise.HandshakeIK,
		Initiator:     false,             // Mac is Responder
		StaticKeypair: noise.DHKey{Private: hostStaticPrivKey},
		Prologue:      []byte("bimax-channel-v1"), // Channel binding string
	})
	if err != nil {
		return nil, fmt.Errorf("failed to init noise handshake: %w", err)
	}

	return &NoiseHostSession{HandshakeState: hs}, nil
}

// ProcessHandshake processes Message 1 (96B) and produces Message 2 (48B)
func (s *NoiseHostSession) ProcessHandshake(msg1 []byte) ([]byte, error) {
	if len(msg1) != 96 {
		return nil, fmt.Errorf("invalid handshake msg1 length: expected 96, got %d", len(msg1))
	}

	// 1. Read Message 1: e, es, s, ss
	_, _, _, err := s.HandshakeState.ReadMessage(nil, msg1)
	if err != nil {
		return nil, fmt.Errorf("failed to process handshake msg1: %w", err)
	}

	// 2. Write Message 2: e, ee, se -> Split()
	msg2, sendCS, recvCS, err := s.HandshakeState.WriteMessage(nil, nil)
	if err != nil {
		return nil, fmt.Errorf("failed to generate handshake msg2: %w", err)
	}

	// In Responder mode: sendCS encrypts Mac->Android; recvCS decrypts Android->Mac
	s.SendCS = sendCS
	s.RecvCS = recvCS

	return msg2, nil
}

// WriteFrame encrypts plaintext and writes 2-byte big-endian length-prefixed frame
func (s *NoiseHostSession) WriteFrame(w io.Writer, plaintext []byte) error {
	ciphertext, err := s.SendCS.Encrypt(nil, nil, plaintext)
	if err != nil {
		return err
	}

	frameLen := uint16(len(ciphertext)) // Length includes 16-byte Poly1305 tag
	header := []byte{byte(frameLen >> 8), byte(frameLen & 0xFF)}

	if _, err := w.Write(header); err != nil {
		return err
	}
	_, err = w.Write(ciphertext)
	return err
}

// ReadFrame reads a 2-byte length-prefixed frame and decrypts it
func (s *NoiseHostSession) ReadFrame(r io.Reader) ([]byte, error) {
	header := make([]byte, 2)
	if _, err := io.ReadFull(r, header); err != nil {
		return nil, err
	}
	frameLen := (uint16(header[0]) << 8) | uint16(header[1])

	buf := make([]byte, frameLen)
	if _, err := io.ReadFull(r, buf); err != nil {
		return nil, err
	}

	return s.RecvCS.Decrypt(nil, nil, buf)
}
```

#### Android Initiator Engine:
```kotlin
package com.bimax.mobile.security

import com.southernthought.snow.CipherState
import com.southernthought.snow.HandshakeState
import com.southernthought.snow.HandshakeConfig
import com.southernthought.snow.ProtocolName
import com.southernthought.snow.Role
import java.io.InputStream
import java.io.OutputStream
import java.security.SecureRandom

class NoiseClientSession(
    private val clientStaticPrivKey: ByteArray,
    private val hostStaticPubKey: ByteArray
) {
    private var sendCipher: CipherState? = null // Android -> Mac
    private var recvCipher: CipherState? = null // Mac -> Android

    fun performHandshake(inputStream: InputStream, outputStream: OutputStream) {
        val protocolName = ProtocolName("Noise_IK_25519_ChaChaPoly_BLAKE2s")
        val config = HandshakeConfig().apply {
            setProtocolName(protocolName)
            setRole(Role.INITIATOR)
            setLocalStaticPrivateKey(clientStaticPrivKey)
            setRemoteStaticPublicKey(hostStaticPubKey)
            setPrologue("bimax-channel-v1".toByteArray(Charsets.UTF_8))
            setRandom(SecureRandom())
        }

        val hs = HandshakeState(config)

        // 1. Generate Message 1 (96 bytes)
        val msg1 = ByteArray(96)
        val written = hs.writeMessage(null, 0, msg1, 0)
        outputStream.write(msg1, 0, written)
        outputStream.flush()

        // 2. Read Message 2 (48 bytes)
        val msg2 = ByteArray(48)
        var totalRead = 0
        while (totalRead < 48) {
            val count = inputStream.read(msg2, totalRead, 48 - totalRead)
            if (count == -1) throw IllegalStateException("EOF during handshake message 2")
            totalRead += count
        }

        val dummyPayload = ByteArray(64)
        hs.readMessage(msg2, 0, totalRead, dummyPayload, 0)

        // 3. Derive bidirectional transport ciphers
        val (csSend, csRecv) = hs.split()
        this.sendCipher = csSend
        this.recvCipher = csRecv
    }

    fun writeEncryptedFrame(outputStream: OutputStream, plaintext: ByteArray) {
        val cipher = sendCipher ?: throw IllegalStateException("Handshake incomplete")
        val ciphertext = ByteArray(plaintext.size + 16)
        cipher.encryptWithAd(null, plaintext, 0, ciphertext, 0, plaintext.size)

        val frameLen = ciphertext.size
        outputStream.write((frameLen shr 8) and 0xFF)
        outputStream.write(frameLen and 0xFF)
        outputStream.write(ciphertext)
        outputStream.flush()
    }

    fun readEncryptedFrame(inputStream: InputStream): ByteArray {
        val cipher = recvCipher ?: throw IllegalStateException("Handshake incomplete")
        val b1 = inputStream.read()
        val b2 = inputStream.read()
        if (b1 == -1 || b2 == -1) throw IllegalStateException("EOF reading frame length")

        val frameLen = (b1 shl 8) or b2
        val ciphertext = ByteArray(frameLen)
        var totalRead = 0
        while (totalRead < frameLen) {
            val count = inputStream.read(ciphertext, totalRead, frameLen - totalRead)
            if (count == -1) throw IllegalStateException("EOF reading ciphertext")
            totalRead += count
        }

        val plaintext = ByteArray(frameLen - 16)
        cipher.decryptWithAd(null, ciphertext, 0, plaintext, 0, frameLen)
        return plaintext
    }
}
```

### 5. Transport Nonce Invariant & Framing

1. **Nonce Construction**: Noise specifies a 96-bit (12-byte) nonce for ChaCha20-Poly1305:
   $$\text{Nonce} = [0, 0, 0, 0] \parallel \text{LE64}(n)$$
   The 64-bit integer $n$ starts at $0$ upon `Split()` and increments by $1$ after every encrypted or decrypted message.
2. **Strict In-Order Transport**: Because the receiver’s counter must match the sender’s counter for AEAD verification to succeed, messages within each unidirectional stream must be processed in order.
3. **Length-Delimited Framing**:
   - `[2 Bytes: Length (Big-Endian)]` + `[Ciphertext: Length - 16 Bytes]` + `[16 Bytes: Poly1305 Tag]`.
