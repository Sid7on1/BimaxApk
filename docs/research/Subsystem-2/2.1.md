### 1. Verification Summary & Cryptographic Architecture

The out-of-band pairing protocol establishes the cryptographic root-of-trust between the macOS host and the Android mobile client **without relying on any central certificate authority or trusted cloud relay**:

1. **Zero Cloud Trust**: Cloudflare operates strictly as an untrusted relay. The Mac's static public key is never stored in or retrieved from a cloud database; it is physically transferred across the visual air-gap via a QR code displayed on the Mac terminal and scanned by the phone.
2. **Binary Struct Packing vs. Verbose JSON**:
   - JSON encoding requires ~280+ bytes due to string field keys, quotation marks, and brackets, forcing a dense **Version 7/8 QR code (45x45 matrix)** that struggles to scan on glossy or dim laptop screens.
   - By serializing fields into a **fixed-order little-endian binary struct**, the entire payload shrinks to **~110–130 bytes**, producing an ultra-scannable **Version 3/4 QR code (29x29 or 33x33 matrix)** with **Error Correction Level M (15% recovery)**.
3. **Unpadded Base64URL Encoding (RFC 4648 §5)**:
   - Uses the URL-safe alphabet (`+` $\rightarrow$ `-`, `/` $\rightarrow$ `_`) with trailing padding (`=`) stripped, ensuring zero character escapes or URL breakage.
4. **Short Authentication String (SAS) 6-Digit Visual Confirmation**:
   - Once Android scans the QR and connects over Cloudflare, both the phone and Mac calculate a 6-digit SAS code:
     $$\text{SAS} = \text{Truncate6Digits}(\text{HMAC-SHA256}(\text{nonce}, \text{mac\_pub} \parallel \text{android\_pub}))$$
   - The user visually confirms the 6-digit number matches on both screens, completely neutralizing Evil Maid and Man-in-the-Middle (MITM) relay attacks.
5. **Android Zero-Permission Scanning**:
   - Utilizes **Google Code Scanner API** (`com.google.android.gms:play-services-code-scanner`), which delegates camera hardware access to Google Play Services. **Zero runtime `CAMERA` permissions are required in `AndroidManifest.xml`**.

### 2. Binary Wire Struct Specification (Little-Endian)

The QR code encodes an unpadded Base64URL string of this exact binary sequence:

```
+-------+-------+----------+---------+------------+----------+----------+------------+----------+-------------+---------+---------+
| v     | type  | ts       | ttl     | nonce_len  | nonce    | mac_pub  | device_id  | fqdn_len | tunnel_fqdn | sig_len | sig     |
| 1B    | 1B    | 8B (u64) | 2B (u16)| 1B (0x10)  | 16B raw  | 32B raw  | 16B (UUID) | 1B       | N bytes     | 1B      | M bytes |
+-------+-------+----------+---------+------------+----------+----------+------------+----------+-------------+---------+---------+
Total Payload Size: ~110 - 130 Bytes (depending on FQDN length)
```

| Field | Size | Data Type | Description |
| :--- | :--- | :--- | :--- |
| `v` | $1\text{ byte}$ | `uint8` | Protocol version (currently `0x01`). |
| `type` | $1\text{ byte}$ | `uint8` | Message type (`0x01` = `pair_init`). |
| `ts` | $8\text{ bytes}$ | `uint64_le` | Creation timestamp (Unix epoch in seconds). |
| `ttl` | $2\text{ bytes}$ | `uint16_le` | Validity lifetime in seconds (e.g., $60\text{s}$ or $120\text{s}$). |
| `nonce_len` | $1\text{ byte}$ | `uint8` | Length of nonce ($16$ bytes). |
| `nonce` | $16\text{ bytes}$ | `raw bytes` | Single-use cryptographic salt generated via CSPRNG. |
| `mac_pub` | $32\text{ bytes}$ | `raw bytes` | Mac host static Curve25519 (X25519) public key. |
| `device_id` | $16\text{ bytes}$ | `UUID (RFC 4122)` | Intended Android device UUID (zeros if pairing any device). |
| `fqdn_len` | $1\text{ byte}$ | `uint8` | Length of tunnel hostname string. |
| `tunnel_fqdn` | Variable | `ASCII string` | Cloudflare tunnel FQDN (e.g., `ws.bimax.dev`). |
| `sig_len` | $1\text{ byte}$ | `uint8` | Length of signature ($0$ if unauthenticated; $32$ for HMAC). |
| `sig` | Variable | `raw bytes` | HMAC-SHA256 signature over preceding bytes. |

### 3. macOS Daemon: Binary Struct Serializer & QR Generator (Go)

```go
package crypto

import (
	"bytes"
	"crypto/hmac"
	"crypto/rand"
	"crypto/sha256"
	"encoding/base64"
	"encoding/binary"
	"fmt"
	"time"

	"github.com/google/uuid"
	"github.com/skip2/go-qrcode"
	"golang.org/x/crypto/curve25519"
)

type BinaryPairingPayload struct {
	Version    uint8
	Type       uint8
	Timestamp  uint64
	TTL        uint16
	Nonce      [16]byte
	MacPub     [32]byte
	DeviceID   [16]byte
	TunnelFQDN string
	Signature  []byte
}

func GenerateBinaryPairingQR(hostPrivKey [32]byte, fqdn string, hmacSecret []byte) (string, error) {
	var macPub [32]byte
	curve25519.ScalarBaseMult(&macPub, &hostPrivKey)

	var nonce [16]byte
	if _, err := rand.Read(nonce[:]); err != nil {
		return "", err
	}

	targetDeviceID := uuid.Nil // Allows initial discovery pairing

	buf := new(bytes.Buffer)
	// 1. Fixed Header
	buf.WriteByte(0x01) // Version 1
	buf.WriteByte(0x01) // Type: pair_init
	_ = binary.Write(buf, binary.LittleEndian, uint64(time.Now().Unix()))
	_ = binary.Write(buf, binary.LittleEndian, uint16(60)) // 60s TTL

	// 2. Nonce & Keys
	buf.WriteByte(byte(len(nonce)))
	buf.Write(nonce[:])
	buf.Write(macPub[:])
	buf.Write(targetDeviceID[:])

	// 3. FQDN
	fqdnBytes := []byte(fqdn)
	buf.WriteByte(byte(len(fqdnBytes)))
	buf.Write(fqdnBytes)

	// 4. Optional Signature
	if len(hmacSecret) > 0 {
		mac := hmac.New(sha256.New, hmacSecret)
		mac.Write(buf.Bytes())
		sig := mac.Sum(nil)
		buf.WriteByte(byte(len(sig)))
		buf.Write(sig)
	} else {
		buf.WriteByte(0x00) // 0-length signature
	}

	// Unpadded Base64URL Encoding (RFC 4648 §5)
	rawBytes := buf.Bytes()
	b64urlPayload := base64.RawURLEncoding.EncodeToString(rawBytes)

	// Generate small, crisp ANSI terminal QR Code (Level Medium)
	qr, err := qrcode.New(b64urlPayload, qrcode.Medium)
	if err != nil {
		return "", err
	}

	fmt.Println("\n=== SCAN TO PAIR (Valid for 60 Seconds) ===")
	fmt.Println(qr.ToSmallString(false))
	fmt.Printf("Payload Size: %d raw bytes (%d b64 characters)\n\n", len(rawBytes), len(b64urlPayload))

	return b64urlPayload, nil
}
```

#### C. Binary Unpacker & Jetpack Compose Scanner (`PairingScanner.kt`)
```kotlin
package com.bimax.mobile.security

import android.content.Context
import android.util.Base64
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.platform.LocalContext
import com.google.android.gms.code.scanner.GmsBarcodeScannerOptions
import com.google.android.gms.code.scanner.GmsBarcodeScanning
import com.google.mlkit.vision.barcode.common.Barcode
import java.nio.ByteBuffer
import java.nio.ByteOrder
import java.util.UUID

data class VerifiedHostConfig(
    val version: Int,
    val timestamp: Long,
    val ttlSeconds: Int,
    val nonce: ByteArray,
    val macPublicKey: ByteArray,
    val deviceId: UUID,
    val tunnelFqdn: String
)

@Composable
fun PairingScannerButton(
    onHostPaired: (VerifiedHostConfig) -> Unit,
    onError: (String) -> Unit
) {
    val context = LocalContext.current
    val options = remember {
        GmsBarcodeScannerOptions.Builder()
            .setBarcodeFormats(Barcode.FORMAT_QR_CODE)
            .enableAutoZoom() // Essential for scanning laptop screens from a distance
            .build()
    }
    val scanner = remember { GmsBarcodeScanning.getClient(context, options) }

    Button(onClick = {
        scanner.startScan()
            .addOnSuccessListener { barcode ->
                val raw = barcode.rawValue ?: return@addOnSuccessListener
                try {
                    val hostConfig = decodeBinaryPairingPayload(raw)
                    onHostPaired(hostConfig)
                } catch (e: Exception) {
                    onError("Invalid pairing payload: ${e.message}")
                }
            }
            .addOnFailureListener { e ->
                onError("Scanner error: ${e.message}")
            }
    }) {
        Text("Scan Pairing QR (No Permission Needed)")
    }
}

fun decodeBinaryPairingPayload(b64url: String): VerifiedHostConfig {
    // 1. Unpadded Base64URL Decode (supports missing trailing padding)
    val rawBytes = Base64.decode(b64url, Base64.URL_SAFE or Base64.NO_PADDING or Base64.NO_WRAP)
    val buffer = ByteBuffer.wrap(rawBytes).order(ByteOrder.LITTLE_ENDIAN)

    // 2. Parse Fixed Header
    val version = buffer.get().toInt() and 0xFF
    val type = buffer.get().toInt() and 0xFF
    if (version != 1 || type != 1) {
        throw IllegalArgumentException("Unsupported protocol version ($version) or type ($type)")
    }

    val timestamp = buffer.long
    val ttl = buffer.short.toInt() and 0xFFFF

    // Check expiration
    val nowSec = System.currentTimeMillis() / 1000
    if (nowSec > (timestamp + ttl)) {
        throw SecurityException("QR code has expired ($ttl seconds elapsed). Generate a new one.")
    }

    // 3. Extract Nonce & Mac Public Key
    val nonceLen = buffer.get().toInt() and 0xFF
    val nonce = ByteArray(nonceLen)
    buffer.get(nonce)

    val macPub = ByteArray(32)
    buffer.get(macPub)

    // 4. Extract Device UUID
    val mostSigBits = buffer.long
    val leastSigBits = buffer.long
    val deviceId = UUID(mostSigBits, leastSigBits)

    // 5. Extract FQDN
    val fqdnLen = buffer.get().toInt() and 0xFF
    val fqdnBytes = ByteArray(fqdnLen)
    buffer.get(fqdnBytes)
    val fqdn = String(fqdnBytes, Charsets.US_ASCII)

    return VerifiedHostConfig(
        version = version,
        timestamp = timestamp,
        ttlSeconds = ttl,
        nonce = nonce,
        macPublicKey = macPub,
        deviceId = deviceId,
        tunnelFqdn = fqdn
    )
}
```

### 5. Short Authentication String (SAS) 6-Digit Visual Confirmation

Once Android connects to the Mac over WebSocket, both sides independently compute a 6-digit confirmation code. If an attacker attempted to intercept the QR or MITM the relay, the codes will not match:

```kotlin
package com.bimax.mobile.security

import javax.crypto.Mac
import javax.crypto.spec.SecretKeySpec
import kotlin.math.abs

object SasConfirmation {
    fun calculate6DigitSas(
        nonce: ByteArray,
        macPubKey: ByteArray,
        androidPubKey: ByteArray
    ): String {
        val hmac = Mac.getInstance("HmacSHA256")
        hmac.init(SecretKeySpec(nonce, "HmacSHA256"))
        
        hmac.update(macPubKey)
        hmac.update(androidPubKey)
        val hash = hmac.doFinal()

        // Extract 4-byte integer from hash and modulo 1,000,000 for 6 digits
        val num = ((hash[0].toInt() and 0x7F) shl 24) or
                  ((hash[1].toInt() and 0xFF) shl 16) or
                  ((hash[2].toInt() and 0xFF) shl 8) or
                  (hash[3].toInt() and 0xFF)

        return String.format("%06d", abs(num) % 1_000_000)
    }
}
```
